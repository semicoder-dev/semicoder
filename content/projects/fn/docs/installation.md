## macOS 安装

Fn 0.8.5（build 21）面向 macOS 14+、Apple Silicon。新用户下载完整安装包，打开 DMG，将 **Fn.app** 拖入 Applications，再从「应用程序」启动。

[下载 Fn 0.8.5](https://github.com/semicoder-dev/fn/releases/download/v0.8.5/Fn-0.8.5-21-mac-arm64.dmg) · [发行说明与校验文件](https://github.com/semicoder-dev/fn/releases/tag/v0.8.5)

安装包已签名、公证，大小为 45,846,716 字节。SHA-256：


| 尚未安装 Fn                                                | 下载上方 DMG 安装。                                        |

0.8.5 是常规修复版，桌面工具栏与列表外壳最大宽度统一为 1200px、水平居中；原生状态栏「显示桌面」置顶，并保留常用应用、系统操作和退出的分组。菜单涉及真实 Swift/AppKit 变更，因此 0.8.4 及更早版本须完整安装一次，不能只靠应用内代码更新获得；这不是仅重编导致的运行时身份漂移。

替换应用保留现有应用、模型连接、业务数据、摘要与偏好，不需要删除数据或重新配置，也无需因本次宿主修复重装独立应用。安装包内置 Bun，使用 Fn 无需自行安装开发工具。桌面正式版暂不提供手机连接。

## 应用内更新

点击「检查更新…」后立即显示检查状态；没有更新时明确提示「已是最新版本」及当前版本。发现更新后显示下载和应用阶段，失败可以重试；重复点击会回到同一窗口，也可选择「在后台继续」。后台自动检查不会弹出无更新或网络失败窗口。

「关于 Fn」显示当前实际运行的版本和 build，应用内代码更新后不再停留在原安装包版本。应用内更新会下载代码，经用户确认后重启后台并刷新界面；请先保存未完成的编辑。更新失败时回到上一份可用代码，业务数据不随代码回退。

从 0.8.4 及更早版本检查到 0.8.5 时，需要按上方步骤完整安装，不是仅下载代码后重启后台。0.8.5 是已登记并通过独立复用验证的新固定运行时基线；后续没有原生变化的普通页面和 TypeScript 更新可复用该基线，通过每版更新验收后进行应用内更新。原生能力、Bun、权限或固定资源变化仍需完整安装包；每版提供 DMG 本身不代表已有用户必须重装。

独立应用在「应用 → 检查更新」中更新，与 Fn 菜单中的桌面更新分开。当前翻译和看板为 0.3.1，笔记和模型目录为 0.3.0。请同时将翻译更新到 0.3.1；它使用 SDK 0.8.0 的完整模型类型和严格校验，失败或中断不保存部分历史。应用更新保留已有业务数据。

## 安装应用

点击底部 Dock 的「应用」，从官方市场安装翻译、笔记、看板和模型目录。也可添加自定义 HTTPS 市场或通过「本地安装」选择 `.fn.tgz`。

安装后从首页应用行打开应用。笔记与看板可直接使用，模型目录联网查询无需 API Key；翻译需在「设置 → 模型」登录 ChatGPT 并选择默认模型。

SDK 0.8.0、UI 0.2.2、翻译 0.3.1 与其余独立应用版本不随本次宿主修复改变；手机与 FIA 独立 npm 不在本次发布范围。

## 源码开发

需要 Bun 1.4.4、Xcode/Swift 6。取得源码后在 Fn 根目录运行：

```sh
bun install --frozen-lockfile --ignore-scripts
bun run dev
# 隔离预览打包代码
bun run run
# 构建本地测试安装包
bun run build --dmg
```

Dev、Preview 使用独立身份和数据。`bun dev` 与 `bun run dev` 等价；保持终端运行，按 Ctrl-C 退出。本机网关通信自动直连，无需关闭 HTTP 代理。0.8.5 对应共仓源码还修复 Bun 1.4.4 的本机开发 readiness 探测受代理影响；这是框架 TypeScript 修复，不改业务 API 或外网代理，也未发布到 FIA 独立 npm。标题栏右侧「在浏览器中打开」连接同一真实宿主。
