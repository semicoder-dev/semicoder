适用于 fn 0.5.0 / SDK 0.4.0 / Chat v3。

## 升级后没有旧连接和应用

新架构采用独立数据目录，旧数据保留但不读取、迁移或删除。请重新创建连接、添加模型和安装 Cordis 应用。旧 SDK 插件、旧 Chat v2 手机端不兼容；不要复制旧数据库或凭证文件。

## 手机看不到模型或主机

确认两端使用同一 iCloud 账号、桌面已运行、配套手机版为 0.3.0（4）。Dev/Preview 使用开发容器，TestFlight 使用生产容器，不能互相发现。手机只展示桌面已添加且仍在账号目录内的模型，空连接隐藏。

## 插件更新一直等待

后台仍有模型、工具或卡片处理任务时不会切换运行目录。先检查任务状态，必要时显式取消；关闭页面不会停止 Agent。候选构建失败时保留原运行目录，查看应用中心错误后修复来源再重试。

## 模型不支持或请求失败

预设目录不是账号权限。确认连接、端点、认证和模型 ID，刷新该账号目录；不要用其他账号兜底。搜索引擎验证码会报告受阻，不能把失败当成零结果。工具请求需要批准时先在会话完成审批。

## 卡片已回复但没有执行

传输确认不等于业务完成，等待宿主持久结果。过期、取消、应用停用或 handler 已销毁会拒绝回复。已认领后失败/崩溃不会自动重放，应由应用检查业务状态后重新发出新卡片。

## 更新提示需要完整安装

原生宿主或运行时变化无法只应用代码更新。下载完整 DMG 替换应用；运行目录与数据格式分别处理，不直接将新数据库交给旧内核。

## 开发浏览器断开

后台重启会使实例连接失效。使用当前实例的 `fn-dev open --browser` 重新连接。重连从 Session 持久投影恢复，临时流式内容不是唯一历史。
