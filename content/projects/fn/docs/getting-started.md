fn 0.5.2 是桌面插件平台，也可以通过独立手机 Chat 控制后台 Agent。首次安装按[下载指南](/fn/docs/installation)完成；0.4.x 或更早版本的模型和插件数据不自动迁移，0.5.x 升级则保留现有数据。

## 安装应用

打开侧栏底部的应用中心，从官方 Cordis 市场安装译文、随手记或网络搜索。宿主不内置这些应用。安装完成后等待后台空闲切换，页面自动重连；侧栏出现已启用的应用入口。

随手记无需模型，输入后显式保存到本地 KV。切页状态可由应用保留，但未保存草稿不会跨重启恢复。

## 添加模型

进入设置 → 模型服务，选择服务商，新建 API Key 连接或订阅登录。为账号命名并将需要的模型加入“已添加模型”。同一服务商可有多个连接，凭证和端点互相隔离。添加模型不产生生成请求，真实权限在调用时验证。

打开译文或网络搜索，选择连接和模型后开始。Session 固定连接；更换账号需要新会话。工具写入和外部副作用默认需要批准。可显式取消任务，关闭页面不会取消。

## 桌面与手机 Chat

安装配套 iPhone 0.3.0（4）内部 TestFlight，在手机和桌面使用同一 iCloud 账号。手机选择主机、应用入口并创建 Session，只展示桌面已添加且仍可用的模型。

离线命令进入本机队列，重连补齐持久历史；多端共享已读、审批及应用卡片。桌面需要运行，退出后手机任务等待恢复。不要将旧 Chat v2 客户端连接到新宿主。

## 外观与窗口

侧栏保持紧凑图标布局，设置有独立二级导航。外观支持浅色、深色、跟随系统以及默认/GitHub/自定义配色；原生标题栏随明暗模式变化。标题栏置顶只影响当前窗口，开发浏览器入口由 FIA 管理。

## 更新

正式桌面启动时和每 24 小时自动检查应用更新，设置页可手动检查、下载与安装。原生运行时变化需要完整 DMG。Dev/Preview 默认关闭正式更新。插件更新从原来源准备完整运行目录，等待任务空闲再切换，持续任务会保持“待应用”。
