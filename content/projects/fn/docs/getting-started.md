fn 0.6.0 启动后进入应用中心。默认界面提供插件管理、模型服务、外观和应用更新；聊天仍在设计中，没有默认会话页面。

## 安装第一个插件

1. 打开应用中心并刷新官方市场。
2. 安装「看板」或「模型目录」。两者均无需 API Key。
3. 等待下载、校验和运行组合准备完成；后台空闲后自动切换，窗口重新连接。
4. 从侧栏进入插件。看板首页可创建多个看板，打开看板后管理列表、卡片、标签与截止日期；模型目录可搜索模型并查看供应商规格和报价。

模型目录只提供信息浏览，不会自动添加模型连接，也不会产生模型调用费用。报价会变化，实际计费以供应商为准。

## 按需配置模型

在设置的模型服务页添加服务商连接，完成 API Key 或订阅认证，再添加需要的模型。模型能力供已安装插件使用；安装看板和模型目录不需要这一步。详见[模型服务与账号](/fn/docs/models)。

外观可选择浅色、深色或跟随系统。窗口菜单可切换置顶。插件界面共享宿主控件和主题。

## 从旧版升级

0.6.0 采用新的插件和数据契约。旧版连接、会话与插件不会自动迁入，需要重新配置；旧数据保留。先阅读[下载与安装](/fn/docs/installation)的升级说明，不要手工复制旧数据库。
