Fn 首页是一张应用桌面。卡片显示最近有效的小组件快照；点击打开独立应用窗口。顶部单行工具栏提供搜索、整理桌面和添加应用；搜索快捷键为 ⌘K。底部 Dock 常驻应用、通知和设置，点击打开对应弹窗。运行中的普通应用位于竖线另一侧，可打开、聚焦或关闭。

重复打开会聚焦窗口；最小化继续后台工作，关闭应用停止任务。存在任务或未保存内容时先确认。关闭桌面窗口只隐藏桌面，退出 Fn 才停止全部应用。再次启动恢复布局和快照，应用默认关闭。

桌面卡片按网格排列，不足一列的剩余宽度均分给各列；最后一行沿用相同列宽，保留未占用的格位。应用通过 size 声明固定的 1×1、2×1、2×2 等规格，表示占用的列数和行数。在「整理桌面」中可排序、移除卡片，应用中心可恢复已移除的卡片。设置提供中英、浅色/深色/跟随系统以及状态栏常用应用。

翻译使用[ChatGPT 账号模型](/fn/docs/models)；笔记与看板在本机保存数据。后台通知从 Dock 的通知入口查看。手机功能仅在开发构建中开放。用户内容保持原文。
