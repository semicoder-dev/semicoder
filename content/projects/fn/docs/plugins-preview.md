> 本页仅描述本地开发候选，尚未发布。正式安装仍是 [fn 0.5.2](/fn/docs/installation)、SDK 0.4.0 和 iPhone 内测 0.3.0（4）。相同源码版本字符串不代表公开产物已经包含本页能力。

## 宿主与默认组合

Bun 和 FIA 提供启动、原生能力、进程和更新基础。原版 dsh 继续提供 Agent、Session、模型适配和工具调度。模型连接、会话控制、Chat、卡片、同步、市场以及前端页面全部由独立 Cordis 插件提供。

默认组合保留紧凑侧栏、模型管理、Chat、应用中心、主题和应用更新。布局也属于插件，可以随 profile 配置替换。宿主只提供 root 挂载位置；默认布局声明侧栏、内容、工具栏、状态和浮层插槽，设置与 Chat 声明自己的子插槽。

前端直接使用 dsh 的模块加载、ui-slots 和 ui-renderer。插件按服务依赖和类型化插槽协作；撤销插件会清理注册、监听和样式。手机继续运行 SwiftUI，不加载桌面 React 插件。

## 新插件契约

自有插件命名为 `@semicoder/fn-<能力名>`。后端导出标准 Cordis apply/Service/inject/Config；Bun 直接执行 TypeScript。可选 `exports["./client"]` 指向构建后的前端。纯后端、纯前端和双端均可；实例 ID 独立于包名，同包可多实例配置。

配置使用有序 bundle 和上游 patch 规则，安装时解析、验证并固定。SDK 仅保留构建、公共契约与泛型客户端，具体业务类型由所属插件导出。FIA 提供可撤销的命名空间 API 注册，避免固定的全业务 Bridge。

## 统一 UI 与主题

默认页面和看板使用同一套 dsh 按钮、输入、菜单、弹窗与图标，通过独立的 `@semicoder/fn-ui` 共享入口提供。插件声明对应 peer，构建时保留共享模块引用；页面只写局部 CSS Modules，并使用 dsh 语义颜色、圆角和层级变量。

基础主题由组合中的主题插件统一加载，浅色、深色、跟随系统和自定义配色继续保留。原生标题栏仍由 FIA 同步明暗。上游主题发行包暂未提供独立 CSS 导出，因此候选固定使用带来源 commit、逐文件哈希和许可证的原样资源；没有复制一套控件实现。

旧 SDK UI、Base UI/Tailwind 实现和全局原生控件样式已经从候选移除。采用旧 UI 导出的插件需要按新契约重建；公开 SDK 0.4.0 的使用说明仍描述已发行产物，不能与本地候选混用。

本候选删除旧应用 SDK、KV、web fetch 和 web search 接口，不提供替代网页工具插件，fn 不再依赖 agent-webtool。三个测试应用从本地官方市场源码移除；生产市场和历史附件尚未改变，正式用户继续使用现有市场。

## 首个应用：看板

“看板”（`fn-kanban`，包名 `@semicoder/fn-kanban`）是为新契约编写的首个正式应用，当前为 0.1.0 本地候选，尚未上架。它支持多个看板、列表与卡片拖动、描述、颜色标签、截止日期、完成状态和检查清单，也支持搜索、筛选、归档与恢复。

数据由插件自己的 SQLite 保存到本机，无需配置模型或云账号。停用、更新和卸载不会删除看板数据，重新安装后继续使用。截止日期用于展示与逾期提示，首版没有提醒推送、附件、多人协作或云同步。

看板通过默认布局的侧栏与主内容插槽贡献页面，不新增宿主专用页面或全局 KV。候选包在隔离宿主和本地 HTTPS 市场中验收；生产索引仍等待新版宿主与插件正式发布，公开 fn 0.5.2 不能安装该候选契约。

## 生命周期与数据

插件仍是可信本机代码。后台任务独立于页面；通用任务服务决定是否空闲。安装、启停、更新和组合修改先生成不可变候选，验证成功后等待空闲，再重启后台并重连窗口。没有 Node HMR。启动失败可恢复上一有效组合或默认组合，布局坏掉时也能使用宿主恢复入口。

新数据根是 `plugins-v1`；Chat 使用独立 v4 zone 和本地目录。不会读取、迁移或删除旧数据。Session 是唯一 Agent 历史，内部卡片、凭证和同步队列各自持久化。手机保留卡片、已添加模型筛选、审批、离线补齐、去重、已读和通知定位。

真实 OAuth、新账号、过期刷新、CloudKit 和设备通知必须单独验收。模拟测试、编译通过与公开发布是不同状态。本轮没有生产部署、TestFlight 上传或市场远端更改。
