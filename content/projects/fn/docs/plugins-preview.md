fn 0.6.1 的官方 schema 3 市场包含两个独立插件，均为 0.1.1，精确使用 SDK 0.5.0。源码和归档见[官方插件仓库](https://github.com/semicoder-dev/fn-plugins)。

0.1.1 优化看板和价格详情弹窗的间距，修复标签弹窗焦点；后端与数据格式不变。在插件市场检查更新并更新已有 0.1.0，保留看板和目录缓存，宿主与 SDK 无需更换。

## 看板

首页创建、重命名和归档多个看板，打开详情后管理列表与卡片。支持拖动排序、跨列表移动、边缘滚动、取消回位和减少动态效果。每张卡片可设置描述、截止日期、完成状态及检查清单。

标签按看板共享，支持名称、30 色或无色、搜索多选和文字/色条切换。删除标签会清理关联；归档列表或卡片可恢复。数据为本机 SQLite schema 2，卸载不自动删除。早期开发 schema 1 文件不读取或迁移。

## 模型目录

从 models.dev 官方目录 API 按需获取数据，以 canonical model 为列表单位，按上游规则关联供应商方案。覆盖对话、图像、视频、嵌入等类型，支持搜索、能力筛选、排序、分页和详情。

缓存一小时，主动刷新联网；失败时保留旧缓存并显示同步时间和错误。报价缺失显示「—」，零价保留为 0，详细价格保留阶梯等字段。信息仅供查阅，实际计费以供应商为准。无需 API Key，不生成内容，不自动添加模型连接。

## 版本边界

旧 SDK 0.4 插件和原来的三个 Cordis 应用不能安装到 0.6。Chat 产品用途待定，正式包不包含聊天入口或同步能力。FIA npm、agent-webtool 和手机内测版本不随本次更新。

## 0.6.1：插件热更新

普通插件安装、更新、启用、停用和卸载在任务空闲后局部生效，不刷新整个页面。未变化插件和页面保留草稿与焦点；被更新插件自身的临时状态可能重建。共享内核、基础组合、嵌套组合及无法安全更新的情况仍重启；失败恢复上一有效组合。原生与浏览器双标签交互已验收。

SDK 保持原版 0.5.0，现有两个官方插件无需重建。新增 hotReload 声明的 SDK 构建支持暂缓，不将它用于当前公开 SDK 归档。
