fn 0.5 的应用中心用于发现、安装和管理 Cordis 应用。新市场与旧 manifest 插件市场分开，旧插件不能直接安装到新宿主。

## 官方与自定义市场

官方 Cordis 市场提供译文、随手记、网络搜索。市场源是静态 HTTPS 索引，可添加或停用自定义来源。市场只登记已公开并核对 SHA-256 的不可变归档。

应用中心支持市场安装、npm、HTTPS tgz、本地归档和 Git 来源。Git 只打包指定 ref 的已提交文件，不运行构建脚本；页面产物需由作者提交。安装前确认来源可信，同进程插件可执行本机代码。

## 管理已安装应用

已安装列表提供打开、更新、停用、启用和卸载。更新保持原来源身份；相同应用 ID、包名和版本对应的内容必须一致。停用释放服务、工具、监听器与页面，卸载保留应用 KV 和 Session 历史。

应用生命周期独立于页面，关闭页面不会取消后台任务。需要停止时使用任务的取消操作。

## 更新过程

每次安装/更新都先准备独立运行目录并检查依赖闭包、共享核心和启动状态。失败保留当前版本。候选就绪后等待所有任务空闲，flush 后重启 Bun；FIA 保留窗口，页面自动重连。

持续任务让更新保持待应用，可以显式取消任务后继续。开发版本同样通过后台重启加载新代码，没有 Node HMR。运行目录回滚不能替代数据库格式回滚。

## 作者入口

参阅[第一个应用](/fn/docs/plugin-development)、[包结构](/fn/docs/plugin-manifest)和[构建分发](/fn/docs/plugin-distribution)。官方应用源码在独立 fn-plugins 仓库的 `examples/cordis`，普通构建不读取相邻宿主源码。
