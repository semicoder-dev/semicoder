## 一个桌面，多个独立应用

Fn 用卡片展示应用状态，点击打开独立窗口。打开启动、最小化继续、关闭停止；状态栏也能快速进入应用。宿主统一管理模型、公共 UI、小组件和应用更新，应用专注业务。

## 翻译、笔记、看板与模型目录

翻译使用 ChatGPT 账号订阅并保存历史；笔记编辑本地内容；看板管理任务、标签、日期与归档。模型目录通过 models.dev API 查阅规格、能力与供应商报价，无需 API Key。页面共享明暗主题和中英界面，数据由应用独立保存。

手机文字中转保留为开发预览，正式手机版本另行发布。

## TypeScript 应用开发

前后端优先使用 TypeScript，后台运行内置 Bun。SDK 提供类型化方法、流式调用、模型、UI、窗口与 JSON 小组件。浏览器调试使用同一真实宿主。

Fn 0.7 提供 macOS Apple Silicon 安装包；开发使用 SDK 0.6.0 与 Fn UI 0.1.0。阅读[下载安装](/fn/docs/installation)、[应用开发](/fn/docs/plugin-development)与[平台架构](/fn/docs/architecture)。
