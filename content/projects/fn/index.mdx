## 应用页面与独立 Chat

fn 把模型连接、Agent、Session、工具、KV 和共享 UI 放在宿主里，让插件专注自己的工作流。侧栏切换应用，每个应用拥有独立页面；同一个后台 Agent 也可由手机 Chat 控制。

## 常用能力

- 译文、随手记和网络搜索从官方应用中心自主安装，宿主不内置插件。
- 同一服务商可创建多个独立 API Key 或订阅连接，选择已添加模型创建会话。
- Agent 支持多轮工具、流式输出、取消和审批；关闭页面不停止任务，重启从持久历史恢复。
- 手机 Chat 通过同一 iCloud 账号同步命令、会话、已读和自定义表单卡片，离线可重试。
- 主题、置顶、SVG 图标、页面状态保留、插件管理与应用自动更新由宿主统一提供。

当前稳定版为 **0.5.1**，已修复官方市场的核心版本误判；从 0.5.0 升级保留现有数据。

从[下载与安装](/fn/docs/installation)开始，再阅读[第一次使用](/fn/docs/getting-started)。不想配置模型时，可以先安装随手记。

## 为插件开发者

fn 0.5 采用 Bun + 原版 dsh / Cordis。后端可以直接运行 TypeScript，浏览器入口是共享 React 的 Cordis 插件。使用 `fn application create/check/build/pack` 创建和分发普通 npm 应用包。

从[应用开发](/fn/docs/plugin-development)、[后端 API](/fn/docs/plugin-backend-api)、[前端 API](/fn/docs/plugin-client-api)和[架构](/fn/docs/cordis-preview)了解新契约。SDK 0.4 与旧 SDK、插件和 Chat v2 不兼容，新数据目录不会读取、迁移或删除旧数据。
